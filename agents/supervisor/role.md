# Assistant Kernel · Supervisor 角色

本项目（`kernel`）的用途：维护执行内核及项目管理：创建、路由、公共模板和确认背景
项目的业务目标、背景、范围和约束见项目章程（`knowledge/charter.md`），工作方法见 assistant-goal-supervisor 等技能。

## 本项目对 Supervisor 的特别要求

- 本项目（kernel）是公开的：它的文件会推送到公开的 GitHub 仓库，任何人都能看到。章程、角色和技能只写通用内容；用户本人、组织、机器环境等具体事实写进公共背景（knowledge/shared/，经卡片由用户确认）或背景信息存档（knowledge/background.md），这两处不随本项目公开。
